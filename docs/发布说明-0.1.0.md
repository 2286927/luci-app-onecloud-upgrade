# v0.1.0 发布说明（候选版，rc1→rc4 汇总）

> OneCloud 专用在线升级 LuCI 应用。只支持 OneCloud（ImmortalWrt 25.12 / apk / ucode LuCI）。
> 最新预发布：<https://github.com/2286927/luci-app-onecloud-upgrade/releases/tag/v0.1.0-rc4>

## 这个应用解决什么

OneCloud 没有 `IMAGE/sysupgrade`，官方刷机页在这里用不了。本应用把设备自带的 `upgrade` 脚本包成图形界面，并补上它缺的部分：

- **固件源可配**：任何 GitHub 仓库 / 静态 HTTPS 目录 / 本地目录，不写死地址；
- **检测与升级分离**：默认只查版本（约 3 秒），不偷偷下 163 MB；
- **演练模式**：`dry_run=1` 时只预检与阶段模拟，不写盘；
- **配置备份与回滚**：写入前自动备份 `/etc/config`，可按备份恢复（默认合并不删新文件）；
- **签名校验**：清单 usign 签名，`require_signature=1` 时无签名/验签失败直接拒绝；
- **诊断包**：一键导出脱敏信息，不用教用户敲命令。

## 验证记录

| 项 | 结果 |
|---|---|
| 真机升级 | 一次真实重刷（同版本 `--force`），串口无 panic，配置与服务恢复 |
| 签名 | 真网络验签通过；篡改清单 rc=6 拒绝；缺 usign/公钥均拒绝 |
| 异常路径 | 故障矩阵 **22/24**（剩 2 条破坏性，见 `破坏性测试预案.md`） |
| 打包 | 公开仓 CI 用 25.12 SDK 构建 5 个 noarch apk，tag 触发自动发版 |
| 安装 | `apk add --allow-untrusted` 纳管，配置保留 |

## 安装

```sh
apk add --allow-untrusted --force-overwrite --repositories-file /dev/null /tmp/*.apk
/etc/init.d/rpcd restart
```

菜单：系统 → OneCloud 升级。详见 [安装与卸载](安装与卸载.md)。

## 已知限制

- **离线升级不可用**：设备脚本 `--url` 模式仍会调 API 取 sha256，无网直接失败。要支持离线，必须改 `/usr/lib/oc-upgrade.sh`（等固件构建额度恢复）。
- **界面仅中文**：i18n 未接入（避免重新引入 luci.mk 注册问题）。
- **默认不强制签名**：`require_signature=0`；建议在自有发布流程稳定后改为 1。
- **应用不会自动进固件**：要么按 [固件接入](固件接入.md) 打进镜像，要么手工装 apk。
- 破坏性场景（写 boot 掉电）未实测，恢复依赖 USB 线刷。

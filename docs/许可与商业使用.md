### 有两件事收不回来，需要如实说明

1. **已经下载到手的旧 apk / 已经 clone 走的代码副本**，技术上无法追回——文件一旦分发就脱离了仓库的控制。
2. **git 历史里仍然存在以 Apache-2.0 授权的提交**。翻看历史 commit（如 `git log -p -- LICENSE`）仍能看到当时的授权文本；要让历史里也不出现，只能重写历史（`git filter-repo` + 强推），代价是所有 commit hash 变化、已有的克隆必须重新拉取。

另外，法律上：**已经按 Apache-2.0 获得这些版本的人，其授权不可撤销**（Apache-2.0 第 2、3 条），他们仍可对**那些旧版本**做包括商业在内的使用。下架改变的是「还能不能从本仓库拿到」，不是「已经拿到的权利」。

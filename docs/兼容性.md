# 兼容性与支持范围

## 支持

| 项 | 范围 |
|---|---|
| 硬件 | OneCloud（Amlogic S805 / meson8b / eMMC） |
| 固件 | ImmortalWrt 25.12（`25.12-SNAPSHOT` 实测） |
| 包管理 | apk（25.12 起） |
| LuCI | ucode + JS 视图（25.12 默认） |
| 包架构 | `noarch`（纯 shell / ucode / JS / JSON，无编译产物） |

## 运行依赖

| 依赖 | 用途 | 设备是否自带（OneCloud 25.12） |
|---|---|---|
| `ucode` + `ucode-mod-fs` + `ucode-mod-uci` | 清单解析 | 是 |
| `jsonfilter` | rpcd 参数解析 | 是 |
| `luci-base` | 页面框架 | 是 |
| `/usr/bin/upgrade` + `/usr/lib/oc-upgrade.sh` | 真正的下载/校验/写入 | 是（固件内置） |

缺任何一个，`check` 或页面会明确报错，不会静默继续。

## 不支持

- **没有 sysupgrade 镜像的机型**：OneCloud 本身就没有 `IMAGE/sysupgrade`，这是本应用存在的原因；反过来，标准 OpenWrt 机型也不该用本应用（请用 `luci-app-attendedsysupgrade` / `owut`）。
- **OpenWrt 23.05 及以下 / opkg**：只出 apk，不提供 ipk。
- **Lua 版 LuCI**（19.07–21.02）：视图是 JS，老前端白屏。
- **NAND / 双分区 / 其他 SoC**：`onecloud-emmc` flasher 是唯一写入实现。

## 已验证矩阵（2026-11-23）

| 场景 | 结果 |
|---|---|
| 25.12-SNAPSHOT / eMMC / apk | 检测、dry-run、真实重刷（T4）、备份、回滚（临时目录）、诊断 均通过 |
| x86/64 25.12 SDK 构建 | 5 个 apk 全部产出，`arch=noarch` |
| apk 安装 | `apk add --allow-untrusted` 成功，文件纳入包管理 |
| 故障注入 | 配置缺失 / 缺 boot 资产 / 平台不符 / 空间不足 / 重复 apply / 非法备份 ID 全部按预期拒绝 |

## 已知限制

- 签名：已支持 usign 清单签名；默认 `require_signature=0`（有签名则校验、无签名放行），设为 `1` 即强制。
- 只支持 stable 通道；beta/dev 明确报未实现。
- 进度是**阶段进度**（预检/备份/写入/收尾），不是字节进度。
- 应用不会自动进入固件；要么按 [固件接入](固件接入.md) 打进镜像，要么手工装 apk。
- **界面仅中文**：i18n 机制未接入（避免重新引入 luci.mk 的注册问题），英文用户请看 README 的 English 摘要。

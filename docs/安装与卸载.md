# 安装与卸载

只支持 OneCloud（ImmortalWrt 25.12 / apk / ucode LuCI）。不支持的固件不要装。

## 方式一：随固件构建（推荐）

把本仓当 feed 引入，构建时编进镜像。步骤见 [固件接入](固件接入.md)。

## 方式二：装 apk（手工）

从本仓 Actions 的 artifact `onecloud-upgrade-packages` 取 5 个 apk，或自行构建：

```sh
# 传到设备
scp fwupgrade-*.apk luci-app-onecloud-upgrade-*.apk root@192.168.1.43:/tmp/

# 设备上安装（本地包未签名，必须 --allow-untrusted）
apk add --allow-untrusted --force-overwrite --repositories-file /dev/null /tmp/*.apk
```

`--repositories-file /dev/null` 表示不联网取依赖；依赖（`ucode`、`jsonfilter`、`luci-base` 等）必须已在固件里。

装完重启 rpcd 让对象注册：

```sh
/etc/init.d/rpcd restart
```

菜单在 **系统 → OneCloud 升级**；命令行 `/usr/libexec/fwupgrade/fwupgradectl`。

## 首次使用

1. 打开页面，填「仓库（owner/name）」与两个资产名（默认值是 OneCloud 官方固件仓的命名）；
2. 保持 **演练模式（dry_run）勾选**，点「检测新版本」→ 再点「升级」，观察阶段迁移；
3. 确认无误后，取消演练模式并保存，才会真正写盘。

配置在 `/etc/config/onecloud-upgrade`，字段：`provider` / `repo` / `base_url` / `asset_rootfs` / `asset_boot` / `channel` / `dry_run` / `force`。

## 卸载

```sh
apk del luci-app-onecloud-upgrade fwupgrade-flasher-onecloud fwupgrade-flasher-dryrun fwupgrade-provider-github fwupgrade-core
/etc/init.d/rpcd restart
```

- `/etc/config/onecloud-upgrade` 会被保留（apk 记为配置文件）；想彻底清掉再手动删。
- `/opt/fwupgrade`（状态、日志、备份、诊断）与 `/opt/upgrade-backup-*` 不会被删，按需手动清理。
- 卸载不会动 `upgrade` 脚本与 boot 分区。
